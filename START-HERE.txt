ZENAI DIGITAL V2 — START HERE

1. DO NOT upload this ZIP itself to GitHub.
2. Extract the ZIP on your Windows PC.
3. The extracted folder is your LOCAL working copy.
4. Use GitHub Desktop to connect/sync the local folder with your GitHub.com repository.
5. GitHub.com is the cloud source of truth.
6. Connect the GitHub.com repository to Cloudflare Workers Builds.
7. Future workflow: edit locally -> build/test -> GitHub Desktop commit -> Push origin -> GitHub.com -> Cloudflare automatic deployment.
